# <p align="center"> hconvcpp
<p align="center"> Hexadecimal Converter (Text String/ASCII To Hex) Rewritten To C++ 
<p align="center"> Originally Compiled With G++ (GNU/GCC) 
<p align="center"> AKA, HCONVPP 


### Setup 
Run `g++ -o hconvpp hconv.cpp` 

### Usage (Files) 
`hconvpp` <br> 

### Usage (Text Input) 
`hconvpp s` <br>
